# 기존 포맷과의 비교

| 항목 | OOXML | AI Studio |
|---|---|---|
| 컨테이너 | zip + XML 파트 | 일반 폴더 |
| 텍스트 추출 | XML 파싱 필요 | md 그대로 |
| 위치 정보 | EMU 좌표 | JSON + 자연어 |
| 청킹 단위 | 파일 전체 | 슬라이드/섹션/시트 |
| 버전 관리 | 바이너리 diff | 텍스트 diff |

## 절충점

폴더 기반이므로 단일 파일 첨부가 어렵다. 배포가 필요하면 폴더를 zip으로 묶되, 편집 중에는 항상 펼쳐진 상태를 유지한다.
