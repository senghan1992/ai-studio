# AI Studio

Office 365처럼 쓰고, AI가 읽을 수 있게 저장하는 오피스 스위트.

| 앱 | 대응 | 확장자 | 저장 방식 |
|---|---|---|---|
| **AI Deck** | PowerPoint | `.aideck` | 슬라이드마다 `내용.md` + `배치.layout.json` |
| **AI Doc** | Word | `.aidoc` | 섹션마다 `내용.md` + `서식.meta.json` |
| **AI Grid** | Excel | `.aigrid` | 시트마다 `투영.md` + `셀.cells.json` |

핵심 아이디어는 하나입니다. **내용은 Markdown에, 배치·계산은 JSON에** 나누어 담고, 저장할 때마다
프로젝트 전체를 요약한 `AI.md`를 함께 생성합니다. `.pptx`처럼 zip 안에 XML을 숨기지 않으므로
`git diff`, `grep`, RAG 인덱서가 모두 그대로 동작합니다.

포맷 전체 스펙은 [`docs/FORMAT.md`](docs/FORMAT.md)에 있습니다.

---

## 실행

```bash
npm install
npm run seed     # 샘플 문서 3개 생성 (선택)
npm run dev      # 서버(5177) + 웹(5178) 동시 실행
```

브라우저에서 **http://localhost:5178** 을 엽니다.

프로덕션처럼 한 포트에서 띄우려면:

```bash
npm run build    # 웹 앱을 apps/web/dist 로 빌드
npm start        # 서버가 5177에서 API와 정적 파일을 함께 제공
```

문서는 `workspace/` 폴더에 저장됩니다. 다른 위치를 쓰려면 `AI_STUDIO_WORKSPACE=/경로` 를 지정하세요.

## 저장 결과 살펴보기

`npm run seed` 후 디스크를 보면 이렇게 생깁니다.

```
workspace/2026-3분기-사업-리뷰.aideck/
├── AI.md                              ← 자동 생성 다이제스트 (RAG용)
├── manifest.json                      ← 슬라이드 순서, 테마
├── assets/                            ← 업로드한 이미지
└── slides/
    ├── 01-2026-3분기-사업-리뷰.md
    ├── 01-2026-3분기-사업-리뷰.layout.json
    ├── 02-핵심-성과.md
    └── 02-핵심-성과.layout.json
```

`02-핵심-성과.md` — 내용만 들어 있고 좌표는 한 글자도 없습니다.

```markdown
---
id: s_9k2mx
title: 핵심 성과
layout: title-content
notes: 전년 동기 대비라는 점을 반드시 짚는다.
---

<!-- block:b_3fh2a -->
# 핵심 성과

<!-- block:b_7dk1p -->
- **매출 142억** — 전년 동기 대비 +24%
- **신규 고객 1,280개사** — 목표의 106%
```

`02-핵심-성과.layout.json` — 좌표와 스타일만 들어 있고 텍스트는 한 글자도 없습니다.

```json
{
  "id": "s_9k2mx",
  "canvas": { "w": 1280, "h": 720, "bg": "#ffffff" },
  "blocks": {
    "b_3fh2a": { "x": 96, "y": 64, "w": 1088, "h": 70, "z": 1, "kind": "text",
                 "style": { "fontSize": 38, "weight": 700 } }
  }
}
```

`AI.md` — 픽셀을 **자연어로 번역**합니다. 이게 이 프로젝트에서 가장 중요한 한 가지입니다.

```markdown
## 슬라이드 2 — 핵심 성과

- 레이아웃: `title-content`
- 발표자 노트: 전년 동기 대비라는 점을 반드시 짚는다.

### 1) 텍스트 — 상단 중앙, 전체 폭

# 핵심 성과

### 2) 텍스트 — 정중앙, 폭 48%

- **매출 142억** — 전년 동기 대비 +24%
```

LLM은 `x=96 y=64 w=1088` 보다 `상단 중앙, 전체 폭` 을 훨씬 잘 이해합니다.

### 스프레드시트가 특히 다릅니다

`.cells.json`이 계산의 원천이고, `.md`는 AI가 읽는 투영입니다. 표에는 **계산된 값**이 열 문자(A·B·C)와
행 번호와 함께 들어가고, 그 아래에 **수식과 결과가 짝으로** 붙습니다.

```markdown
|     | A | B | C | D | E | F |
|---|---|---|---|---|---|---|
| **1** | **항목** | **10월** | **11월** | **12월** | **분기 합계** | **비중** |
| **2** | 인건비 | ₩480,000,000 | ₩495,000,000 | ₩495,000,000 | ₩1,470,000,000 | 48.0% |

### 수식
- `E2` = `=SUM(B2:D2)` → ₩1,470,000,000
- `F2` = `=E2/$E$7` → 48.0%

### 열 요약
집계 대상: 2–7행 (집계 행 7행 제외)

| 열 | 머리글 | 유형 | 값 개수 | 합계 | 평균 | 최소 | 최대 |
|---|---|---|---|---|---|---|---|
| B | 10월 | 숫자 | 5 | 964,000,000 | 192,800,000 | 46,000,000 | 480,000,000 |
```

덕분에 AI는 `"D4의 합계는?"`, `"비중이 가장 큰 항목은?"` 같은 질문에 **셀 주소로** 답할 수 있습니다.
열 요약은 합계 행을 제외하고 계산하므로 시트 자체의 합계와 항상 일치합니다 — 틀린 숫자를 주는 요약은
없는 요약보다 나쁘기 때문입니다.

### 차트도 그림이 아니라 숫자로 저장됩니다

차트는 Deck·Doc에서는 ```` ```chart ```` 블록, Grid에서는 셀 범위를 가리키는 부동 개체입니다.
어느 쪽이든 `.md`와 `AI.md`에는 **차트를 그리는 숫자가 표로** 들어갑니다.

```markdown
### 차트

- 세로 막대 차트 "분기별 매출" — 계열 2개(2025, 2026), 항목 4개 (범위 `A1:D5`)

  | 구분 | 2025 | 2026 |
  |---|---|---|
  | 1분기 | 98 | 120 |
```

## 마크다운을 직접 고쳐도 됩니다

이 포맷은 단방향이 아닙니다.

- **슬라이드 md에 블록을 손으로 추가**하면 다음에 열 때 자동 레이아웃을 받아 나타납니다.
- **`.aigrid`의 md만 있고 `.cells.json`이 없으면** 마크다운 표를 읽어 시트를 만듭니다.
- **Doc의 md는 기본 서식일 때 순수 마크다운**입니다. 서식을 준 문단만 `<!-- block:id -->` 앵커를
  갖고, 서식을 되돌리면 앵커도 사라집니다.
- **차트의 셀 범위가 깨져도** 스펙에 남은 값으로 그립니다.

즉 AI 에이전트가 마크다운만 써서 문서를 만들거나 고칠 수 있습니다.

## 조작법

세 앱 모두 Office와 같은 리본을 씁니다. **파일** 탭에 새로 만들기 · 열기 · 저장 · 사본 만들기 ·
내보내기가 있고, 어디서나 `Ctrl+S`·`Ctrl+Z`·`Ctrl+Shift+Z`, 우클릭 컨텍스트 메뉴, 상태 표시줄의
확대/축소 슬라이더가 동작합니다. 편집을 멈추면 2.5초 후 자동 저장되고, 그때마다 md/json과 `AI.md`가
다시 쓰입니다. 제목을 바꾸면 폴더 이름도 따라갑니다.

**Deck** — 블록을 끌어 옮기고 8방향 핸들로 크기를 바꿉니다. 다른 블록과 캔버스 중심선에 스냅되며
(`Alt`로 해제), 화살표키로 8px씩(`Shift`와 함께 1px씩) 이동합니다. 블록을 두 번 누르면 그 자리에서
마크다운을 편집하고, `Ctrl+B`/`Ctrl+I`가 `**`/`*`를 넣습니다. `Ctrl+C`/`X`/`V`/`D`로 요소를
복사·잘라내기·붙여넣기·복제하고, 리본의 맞춤·분배 버튼으로 캔버스에 정렬합니다.
**`F5`로 슬라이드 쇼**를 시작하면 `→`/`Space`로 이동, `S`로 발표자 노트, `Esc`로 종료합니다.

**Doc** — 문단을 누르면 마크다운 편집으로 바뀝니다. `Enter`는 새 문단(목록 안에서는 목록 계속),
`Shift+Enter`는 줄바꿈, 문단 맨 앞에서 `Backspace`는 이전 문단과 합칩니다. 블록 높이를 실제로 측정해
**A4/Letter/A5 페이지로 나누고**, `Ctrl+Enter`로 페이지 나누기를 넣고, `Ctrl+P`로 인쇄/PDF를 냅니다.
`Ctrl+F`/`Ctrl+H`로 찾기·바꾸기.

**Grid** — 화살표/`Tab`/`Enter`로 이동, 아무 글자나 입력하면 편집 시작, `F2`로 수정, `Delete`로 지우기.
선택 영역 우하단의 **자동 채우기 핸들**을 끌면 등차수열·수식(상대 참조 이동)·`ID-008`류 텍스트가
이어집니다. 열/행 경계를 끌어 크기를 바꾸고(두 번 누르면 자동 맞춤), **이름 상자**에 `D3`이나 범위
이름을 입력해 이동하고, 셀 병합·테두리·틀 고정이 동작합니다. `Ctrl+C`는 값을, `Ctrl+Shift+C`는 수식을
TSV로 복사하므로 Excel과 오갈 수 있습니다. `Ctrl+V`는 TSV와 마크다운 표를 모두 붙여넣습니다.
`` Ctrl+` ``로 수식 보기를 켜고, 수식 셀을 고르면 참조하는 셀에 테두리가 표시됩니다. 행/열을
삽입·삭제하면 수식 참조가 자동으로 따라갑니다.

오른쪽 **`{ } 저장 포맷`** 패널은 지금 이 순간 디스크에 쓰일 md와 json을 그대로 보여줍니다.
브라우저와 서버가 같은 직렬화 코드를 쓰기 때문에 실제 저장될 내용과 바이트 단위로 같습니다.

### 내보내기

| 앱 | 형식 | 무엇이 넘어가는가 |
|---|---|---|
| Deck | `.pptx` | 좌표·서식·발표자 노트·표·이미지, 그리고 **PowerPoint에서 편집 가능한 네이티브 차트** |
| Doc | `.docx` | 용지·여백·제목 스타일·목록·표·인용·코드·이미지·문단 서식 |
| Grid | `.xlsx` | **수식이 살아 있는 채로**, 표시 형식·셀 스타일·병합·틀 고정·이름 범위 |
| Grid | `.csv` | 현재 시트의 값 (Excel 한글용 BOM 포함) |
| 전부 | `AI.md` | RAG에 그대로 넣는 다이제스트 |

## 구조

```
packages/formula/   수식 엔진 — 렉서, 파서, 평가기, 함수 90여 개, 재계산, 참조 조정
packages/format/    포맷 라이브러리 — md/json 파싱·직렬화, 차트 렌더러, AI.md 생성, 파일 I/O
apps/server/        Express — 프로젝트 CRUD, 이미지 자산, Office 내보내기, 서버측 재계산
apps/web/           React — 런처 + 세 에디터, 저장 포맷 패널
docs/FORMAT.md      포맷 스펙
scripts/            seed, e2e, export-check, ui-smoke, restart-server
```

`packages/format`은 두 개의 진입점을 갖습니다: 기본(`node:fs` 포함)과 `./browser`(파서만).
웹 에디터가 후자를 쓰기 때문에 브라우저와 서버가 같은 파서·같은 차트 렌더러를 공유합니다.

차트 팔레트는 색각 이상 대비를 검증한 8색 고정 순서이고, 밝은/어두운 배경에 각각 다른 단계를
씁니다. 9번째 계열은 새 색을 만들지 않고 `기타`로 합칩니다.

## API

에이전트나 스크립트가 UI 없이 문서를 다룰 수 있습니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/api/projects` | 목록 |
| `POST` | `/api/projects` | 생성 `{ type, title }` |
| `GET` | `/api/projects/:folder` | 전체 내용 |
| `PUT` | `/api/projects/:folder` | 저장 (md/json/AI.md 재생성) |
| `PATCH` | `/api/projects/:folder` | 제목·폴더명 변경 `{ title }` |
| `DELETE` | `/api/projects/:folder` | 삭제 |
| `GET` | `/api/projects/:folder/files` | 파일 목록 |
| `GET` | `/api/projects/:folder/file?path=` | 파일 내용 |
| `GET` | `/api/projects/:folder/digest` | `AI.md` |
| `GET` | `/api/projects/:folder/export/:ext` | `pptx` · `docx` · `xlsx` · `csv` |
| `GET` `POST` | `/api/projects/:folder/assets` | 이미지 목록 / 업로드 `{ name, dataUrl }` |
| `GET` | `/api/projects/:folder/asset?path=` | 이미지 제공 |
| `POST` | `/api/recalc` | 시트 재계산 `{ cells, names }` |

폴더 파라미터는 작업 폴더 밖을 벗어나지 못하도록 검증되고, 자산은 `assets/` 안만 읽힙니다.

## 검증

```bash
npm test                       # 단위 테스트 170개
./scripts/restart-server.sh    # 서버를 백그라운드로 재시작하고 준비될 때까지 대기
node scripts/e2e.mjs           # API·디스크 검증 60개
node scripts/export-check.mjs  # Office 파일 구조 검증 72개 (unzip 필요)
```

- **`e2e.mjs`** — 세 문서 타입을 실제로 만들고 편집해 저장한 뒤 **디스크에 쓰인 파일**을 열어
  확인합니다. 좌표가 md로 새지 않는지, 텍스트가 json으로 새지 않는지, 손으로 고친 마크다운이 다시
  열리는지, 경로 탈출이 막히는지까지.
- **`export-check.mjs`** — 만들어진 `.pptx`/`.docx`/`.xlsx`의 zip을 풀어 XML을 검사합니다. 수식이
  값이 아니라 수식으로 나갔는지, 병합·틀 고정·이름 범위가 각 형식의 요소로 변환됐는지, pptx에
  네이티브 차트 파트가 생겼는지.
- **`ui-smoke.mjs`** — 실제 React 앱을 jsdom에 마운트해 **95개**를 검사합니다. 렌더링뿐 아니라
  편집 상호작용까지: 셀 입력이 의존 수식을 연쇄 재계산하는지, 자동 채우기가 등차수열을 이어가는지,
  `F5`가 슬라이드 쇼를 띄우고 방향키로 넘어가는지, 차트 삽입이 SVG를 그리는지, 페이지 나누기가 페이지를
  늘리는지. `jsdom`과 `esbuild`가 필요합니다.

```bash
npm i -D jsdom esbuild
AI_STUDIO_TOOLS=$(pwd) node scripts/ui-smoke.mjs
```

브라우저를 띄워 눈으로 확인한 것은 아닙니다 — 이 환경에 headless 브라우저를 실행할 시스템
라이브러리가 없어서, 렌더링 검증은 jsdom과 SVG 출력 감사(마크 규격·레이블 충돌·대비)까지입니다.

## 현재 한계

- **`.docx`·`.xlsx`에는 네이티브 차트가 없습니다.** `.pptx`만 편집 가능한 차트로 나가고, Word는 차트를
  데이터 표 + 캡션으로, Excel은 데이터 블록으로 씁니다(사용한 라이브러리가 차트 파트를 쓰지 못함).
- **PDF는 브라우저 인쇄로만 만듭니다.** Doc은 `Ctrl+P` → PDF로 저장이 되지만, Deck·Grid는 서버에서
  PDF를 생성하지 않습니다.
- **동시 편집을 가정하지 않았습니다.** 저장은 마지막 쓰기가 이깁니다.
- **Doc의 페이지 나눔은 블록 단위입니다.** 한 문단이 페이지 경계를 넘으면 문단 전체가 다음 장으로
  넘어갑니다(Word와 같은 동작). 다만 페이지보다 큰 문단은 잘리지 않고 그 페이지를 넘칩니다.
- **머리글·바닥글·각주·목차 자동 생성이 없습니다.** 페이지 번호는 화면에만 표시됩니다.
- **셀 서식 대화상자, 조건부 서식, 필터가 없습니다.** 정렬은 선택 범위의 첫 열 기준만 지원합니다.
